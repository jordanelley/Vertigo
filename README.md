# Vetigo

Monorepo with two frontends and a shared backend.

## Structure

- `web/` — React + TypeScript frontend (Vite)
- `mobile/` — React Native frontend (Expo, TypeScript)
- `api/` — Backend (.NET Core Web API, C#)

## Getting started

### Web

```sh
cd web
npm install
npm run dev
```

### Mobile

```sh
cd mobile
npm install
npm start
```

### API

```sh
cd api
dotnet run
```
